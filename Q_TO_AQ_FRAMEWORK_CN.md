# SubgraphRAG：从问题 q 到最终答案 A_q 的流程说明（含 ASCII 流程图）

> 说明：严格地说，论文中的 `A_q` 通常表示真实答案（ground truth）；系统输出通常记作 `\hat{A}_q`。为方便阅读，下文口语化地称为“最终答案”。

## 1) 一句话总览

SubgraphRAG 是一个两阶段流程：

- **检索阶段（Retriever）**：`q -> \hat{G}_q`（从 KG 中选出 top-K 相关三元组）
- **推理阶段（LLM Reasoner）**：`(q, \hat{G}_q) -> \hat{A}_q`（让 LLM 基于三元组回答）

                 │
                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│ (A) 预处理候选子图（围绕 topic entities 的粗子图）                    │
│     候选三元组集合: τ=(h,r,t), 共 N 条                                │
└──────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│ (B) 语义编码（GTE-large-en-v1.5）                                    │

└──────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│ (C) 结构编码 DDE（以 topic entity 为源，正向+反向扩散）               │

│     实体结构向量 s_e 维度 = 2 + 2*(2+2) = 10                          │

                 │
                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│ (D) 三元组打分 MLP                                                    │
│     x_τ = [z_q || z_h || z_r || z_t || s_h || s_t]                   │
│     dim(x_τ)=4*1024+10+10=4116                                        │
│     MLP: 4116 -> 1024 -> 1                                            │
│     score_τ = sigmoid(logit_τ)                                        │
└──────────────────────────────────────────────────────────────────────┘
                 │
                 ▼
┌──────────────────────────────────────────────────────────────────────┐
│ (E) 排序并取 Top-K（K=100/200/500 等）                                │

## 3) 训练与推理分别在做什么

### 3.1 检索器训练（Stage-1 train）

目标不是直接优化 LLM 输出，而是用弱监督训练三元组分类器：

- 弱监督标签来自“topic entity 到 answer entity 的最短路径三元组”
- 命中最短路径的三元组记为正样本（1），其他为负样本（0）
- 用 BCE loss 训练 MLP 打分器

### 3.2 检索推理（Stage-1 inference）

- 加载 `cpt.pth`（模型参数）
- 对测试集每个问题的候选三元组逐条打分并排序
- 输出 `retrieval_result.pth`（这是结果文件，不是新权重）

### 3.3 LLM 推理（Stage-2 reason）

- 读取 `retrieval_result.pth` 或作者提供的 `scored_triples/*.pth`
- 根据 `prompt_mode`（如 `scored_100`）取前 K 条三元组进 prompt
- 由 LLM 生成答案列表（`ans:`）

---

## 4) 关键维度小抄

- 文本语义向量：`1024` 维（问题/实体/关系）
- DDE 实体结构向量：`10` 维（默认配置下）
- 三元组结构向量：`20` 维（`s_h || s_t`）
- MLP 输入总维度：`4116`

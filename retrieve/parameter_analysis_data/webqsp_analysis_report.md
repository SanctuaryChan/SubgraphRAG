# WebQSP Stage-3 参数敏感性分析报告

## 1. 实验设置

- 数据来源：`webqsp_sweep_pseudo_stage3/all_results.csv`
- 数据集：`webqsp`
- 模式：`target_mode=pseudo`
- 评估口径：`all-sample-zero-fill`
- 固定参数：`k_eval=20`，`candidate_k=500`，`alpha=0.5`，`beta=0.2`，`pseudo_pool_k=100`，`pseudo_top_m=3`
- 搜索网格：
  - `delta ∈ {3,4,5,6}`
  - `p_near ∈ {8,9,10,11,12,13,14,15}`
  - `b_type ∈ {12,14,16,18,20}`
- 组合数：`4 × 8 × 5 = 160`

## 2. 全局结果概览

- 全局最优配置：
  - `delta=3, p_near=11, b_type=20`
  - `AER@20=0.774939`
  - `PathCoverage@20=0.849908`
  - `score=0.812424`（`score = 0.5*AER + 0.5*PC`）
- 全局最差配置：
  - `delta=4, p_near=8, b_type=12`
  - `score=0.807115`
- 指标波动范围（max-min）：
  - `AER@20`: `0.007835`
  - `PathCoverage@20`: `0.008541`
  - `score`: `0.005309`

结论：本轮网格内有稳定提升空间，但总体波动幅度中等，未出现剧烈不稳定。

## 3. 三个参数的敏感度分析

### 3.1 `p_near`（最敏感）

按 `p_near` 的 `score` 边际均值：

| p_near | mean(score) |
|---|---:|
| 8 | 0.808139 |
| 9 | 0.808622 |
| 10 | 0.809777 |
| 11 | **0.810719** |
| 12 | 0.809622 |
| 13 | 0.808975 |
| 14 | 0.809830 |
| 15 | 0.809390 |

观察：
- 峰值在 `p_near=11`，`10~12` 是高性能主区间。
- `p_near` 从 `11` 继续增大没有持续收益。
- 与最优值相比，`p_near=10` 的差距仅 `0.000684`，属于可接受替代点。

### 3.2 `delta`（中等敏感）

按 `delta` 的 `score` 边际均值：

| delta | mean(score) | best(score) |
|---|---:|---:|
| 3 | **0.810216** | **0.812424** |
| 4 | 0.808891 | 0.810003 |
| 5 | 0.809234 | 0.810308 |
| 6 | 0.809196 | 0.810308 |

观察：
- `delta=3` 在均值和最优值上都最好。
- `delta=5` 与 `delta=6` 几乎重合，继续加大 `delta` 的价值较低。

### 3.3 `b_type`（弱敏感）

按 `b_type` 的 `score` 边际均值：

| b_type | mean(score) | best(score) |
|---|---:|---:|
| 12 | 0.809317 | 0.812350 |
| 14 | 0.809334 | 0.812350 |
| 16 | 0.809404 | 0.812378 |
| 18 | 0.809425 | 0.812406 |
| 20 | **0.809441** | **0.812424** |

观察：
- `b_type` 增大时性能略有提升，但提升幅度很小。
- `b_type=16~20` 已处于近平台区域，可优先用较大值保证稳健性。

## 4. 近最优区域（用于“稳健结论”）

以全局最优 `score=0.812424` 为基准：

- 在 `best - 0.0005` 内：
  - 仅出现 `delta=3, p_near=11`
  - `b_type ∈ {12,14,16,18,20}`
- 在 `best - 0.001` 内：
  - `delta=3`
  - `p_near ∈ {10,11}`
  - `b_type ∈ {12,14,16,18,20}`
- 在 `best - 0.002` 内：
  - `delta=3`
  - `p_near ∈ {10,11,12}`
  - `b_type ∈ {12,14,16,18,20}`

解释：
- 最优附近几乎完全由 `delta=3` 主导。
- `p_near` 的有效窗口窄于 `delta` 与 `b_type`，是本次调参的关键杠杆。

## 5. 建议结论（可直接写入正文）

- 本轮 WebQSP最优配置为：
  - **`delta=3, p_near=11, b_type=20`**
- 若强调稳健而非单点最优，可使用：
  - **`delta=3, p_near=10~12, b_type=16~20`**
- 后续不建议继续“外扩搜索范围”，建议：
  - 固定 `delta=3`；
  - 仅对 `p_near` 在 `10~12` 做细化；
  - `b_type` 维持在 `16~20` 即可。
